# Security Notes

The original development files contained live Wi-Fi credentials and a Telegram Bot API credential file. Those values are **not included** in this repository. Firmware credentials have been replaced with placeholders and only `BotAPI.example.txt` is provided.

If any original credential was ever shared outside the team or committed elsewhere, rotate it before reuse. In particular, regenerate the Telegram bot token in BotFather and update local configuration.
